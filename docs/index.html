功能特性

一站式管理 Agent 技能的全部流程

一个应用，覆盖 AI Agent 技能从搜索到卸载的完整生命周期。

🔍

搜索与发现

基于 npx skills find 搜索完整技能目录，一目了然地查看描述、源仓库和兼容性。

📦

全局 & 项目范围安装

支持全局安装或指定项目目录安装。项目范围安装需显式选择目标路径，防止误写入。

🤖

多 Agent 支持

读取官方 Agent 目录，仅展示本机已检测到的 Agent，未检测到的目标不会被默认选中。

📜

实时命令日志

每次安装、更新或移除都实时流式展示 stdout/stderr，日志同步写入系统应用日志目录。

🔄

更新与移除

查看全部已安装技能，检查更新，一键干净移除——无需打开终端。

🌐

双语界面

完整的中文与英文界面支持，无需重启即可切换语言。

快速开始

下载适合你平台的版本

macOS、Windows、Linux 均提供预构建安装包。需要系统已安装 Node.js 和 npx。

macOS Windows Linux
# 前置要求
node --version # 需要 Node.js

# 启动 skills CLI
npx skills list

# 然后打开 SkillDeck 享用 GUI ↑
